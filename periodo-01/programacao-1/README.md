# Programação 1

## Resumo dos códigos

- `conta.h`: Define os tipos, constantes, códigos de erro e assinaturas das funções do sistema bancário simples (conta corrente, poupança e extrato).
- `conta.c`: Implementa as operações da conta (depósito, saque, aplicação e resgate), controle de saldo e registro de transações com data/hora para impressão de extrato.
- `contaMain.c`: Executa testes automáticos básicos do sistema bancário e oferece um menu interativo no terminal para operar a conta e consultar extrato/saldos.
- `geometria.c`: Calcula áreas de figuras planas e sólidos (como quadrado, círculo, cubo, cone e cilindro) a partir de valores informados pelo usuário.
- `struct1.c`: Lê dados de alunos em uma struct, calcula médias, média da turma, identifica a maior média e conta quantos alunos ficaram abaixo/igual à média geral.
- `struct2.c`: Lê um vetor inteiro e gera outro vetor em que cada posição é a soma do elemento atual com seus vizinhos imediatos.
- `validacao_parte1.c`: Valida formatos de números de telefone, remove DDD quando existe e extrai o DDD em números válidos, com exemplos de teste no `main`.
- `validacao_parte2.c`: Analisa uma data no formato textual `xx/yy/zz` e informa quais interpretações de formato (dd/mm/yy, mm/dd/yy, yy/mm/dd) são válidas.
